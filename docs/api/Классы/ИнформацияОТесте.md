# ИнформацияОТесте

Сведения о текущем тесте или наборе, получаемые через [`&ИнформацияОТесте`](../Аннотации/ИнформацияОТесте.md).

Сохранённый объект продолжает описывать узел на момент получения. Подготовка следующего теста
обновляет поле одиночки новым объектом и сохраняет прежние сведения у ранее полученных ссылок.

## ОтображаемоеИмя

```bsl
// Возвращает отображаемое имя текущего теста или набора.
// Для повторения и параметризованного вызова возвращает имя конкретной итерации.
//
// Возвращаемое значение:
//  Строка - Отображаемое имя
//
Функция ОтображаемоеИмя() Экспорт
```

## Теги

```bsl
// Возвращает теги текущего узла, включая теги тестового набора.
//
// Возвращаемое значение:
//  ФиксированноеМножество из Строка - Теги без повторений
//
Функция Теги() Экспорт
```

## Набор

```bsl
// Возвращает тип сценария тестового набора.
//
// Возвращаемое значение:
//  Тип - Тип сценария, которому принадлежит текущий тест
//
Функция Набор() Экспорт
```

## Метод

```bsl
// Возвращает описание исходного тестового метода.
// Для повторения и параметризованного вызова возвращает метод шаблона.
//
// Возвращаемое значение:
//  Опциональный - ИнформацияОМетоде; пустой - текущий узел является набором
//
Функция Метод() Экспорт
```

Описание метода имеет тип [ИнформацияОМетоде](ИнформацияОМетоде.md).
