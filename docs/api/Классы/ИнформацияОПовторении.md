# ИнформацияОПовторении

Сведения о текущем повторении, получаемые через [`&ИнформацияОПовторении`](../Аннотации/ИнформацияОПовторении.md).
Полученный объект сохраняет номер и количество на момент получения.

## ТекущееПовторение

```bsl
// Возвращает номер текущего повторения.
//
// Возвращаемое значение:
//  Число - Номер повторения, начиная с единицы
//
Функция ТекущееПовторение() Экспорт
```

## ВсегоПовторений

```bsl
// Возвращает общее количество повторений теста.
//
// Возвращаемое значение:
//  Число - Количество повторений
//
Функция ВсегоПовторений() Экспорт
```
