# ИнформацияОМетоде

Неизменяемое описание исходного тестового метода. Возвращается методом
[`ИнформацияОТесте.Метод()`](ИнформацияОТесте.md#метод).

## Имя

```bsl
// Возвращает имя метода в сценарии тестового набора.
//
// Возвращаемое значение:
//  Строка - Имя метода
//
Функция Имя() Экспорт
```

## Набор

```bsl
// Возвращает тип сценария, в котором объявлен метод.
//
// Возвращаемое значение:
//  Тип - Тип сценария тестового набора
//
Функция Набор() Экспорт
```
