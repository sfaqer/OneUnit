# ИнформацияОПараметризованномВызове

Сведения о конкретном вызове, получаемые через
[`&ИнформацияОПараметризованномВызове`](../Аннотации/ИнформацияОПараметризованномВызове.md).

## НомерВызова

```bsl
// Возвращает номер вызова среди значений источников текущего тестового метода.
//
// Возвращаемое значение:
//  Число - Номер вызова, начиная с единицы
//
Функция НомерВызова() Экспорт
```

Нумерация начинается заново для каждого метода и не зависит от отображаемого имени вызова.

## Аргументы

```bsl
// Возвращает аргументы, предоставленные источником для текущего вызова.
// Список доступен только для чтения.
//
// Возвращаемое значение:
//  ФиксированныйСписок из Произвольный - Аргументы источника
//
Функция Аргументы() Экспорт
```

Индексы начинаются с нуля. Список содержит позиционные значения, подготовленные источником.
Параметры, которые OneUnit заполняет по аннотациям, например
[`&ИнформацияОТесте`](../Аннотации/ИнформацияОТесте.md), в список не включаются.
Значения по умолчанию автоматически не подставляются.
Список доступен только для чтения; переданный конструктору изменяемый список копируется.
