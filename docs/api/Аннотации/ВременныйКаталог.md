# АннотацияВременныйКаталог

## ПриСозданииОбъекта

```bsl
// Передает путь к временному каталогу в параметр или поле набора.
// При первом обращении создаёт пустой каталог.
// Каталог удаляется при закрытии области с учётом режима очистки.
//
// Параметры:
//  Область - Строка - "Тест": параметр получает путь к новому каталогу при каждом вызове
//    метода или конструктора. Поле получает новый путь перед каждым тестом.
//    Каталог удаляется после теста. В конструкторе одиночки, ПередВсеми и ПослеВсех - после набора.
//    "Набор" использует один каталог для данного параметра или поля во всех экземплярах набора.
//  Очистка - Строка - "Всегда", "ПриУспехе" или "Никогда".
//    ПриУспехе сохраняет каталог при ошибке в области. Пустой каталог удаляется всегда.
//    Путь оставленного каталога записывается в лог на уровне Информация.
//    При включённом уровне сообщение попадает в вывод теста или набора и отчёты.
//
// Пример:
//  &Тест
//  Процедура Проверка(&ВременныйКаталог Каталог) Экспорт
//      Сообщить(Каталог);
//  КонецПроцедуры
//
Процедура ПриСозданииОбъекта(Область = "Тест", Очистка = "Всегда")
```
