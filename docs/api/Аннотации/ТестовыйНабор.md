# АннотацияТестовыйНабор

## ПриСозданииОбъекта

```bsl
// Объявляет сценарий тестовым набором и задает жизненный цикл его экземпляров.
// Размещается над конструктором сценария.
//
// Параметры:
//  Характер - Строка - Режим использования экземпляров набора:
//   `Одиночка`     - один экземпляр на прогон для всех тестов набора.
//   `Компанейский` - отдельный экземпляр для каждого теста.
//   Значение по умолчанию: `Компанейский`
//
// Пример:
//  &ТестовыйНабор(Характер = "Одиночка")
//  Процедура ПриСозданииОбъекта()
//  КонецПроцедуры
//
Процедура ПриСозданииОбъекта(Характер = "Компанейский")
```
