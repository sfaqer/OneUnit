# АннотацияИнформацияОТесте

## ПриСозданииОбъекта

```bsl
// Передает сведения о текущем тесте или наборе в параметр конструктора,
// тестового метода, метода жизненного цикла или в поле набора.
// Поля получают значение после проверки условий и перед методами текущего узла.
//
// Тестовый метод, ПередКаждым и ПослеКаждого получают сведения о выполняемом тесте.
// У компанейского набора каждый тест выполняется на отдельном экземпляре набора.
// Конструктор этого экземпляра получает сведения о тесте, который будет на нём выполнен.
// ПередВсеми, ПослеВсех и конструктор одиночки получают сведения о наборе целиком.
// При вычислении выражения источника или совета уровня Поделка параметр конструктора
// получает Неопределено. Для совета уровня Процесс экземпляр создается без аргументов:
// обязательные параметры исключают создание, а необязательные получают значения по умолчанию.
//
// Пример:
//  &Тест
//  Процедура Проверка(&ИнформацияОТесте Информация) Экспорт
//      Сообщить(Информация.ОтображаемоеИмя());
//  КонецПроцедуры
//
Процедура ПриСозданииОбъекта()
```

Возвращаемое поставщиком значение имеет тип [ИнформацияОТесте](../Классы/ИнформацияОТесте.md).
