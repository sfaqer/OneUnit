# АннотацияИнформацияОПовторении

## ПриСозданииОбъекта

```bsl
// Передает информацию о текущем повторении в параметр повторяемого теста,
// ПередКаждым, ПослеКаждого или в поле набора перед выполнением повторения.
// В обычном тесте, параметризованном вызове, конструкторе, ПередВсеми и ПослеВсех
// значение недоступно: запрос вызывает ошибку разрешения значения.
// Умолчание параметра не используется при ошибке поставщика.
//
// Пример:
//  &ПовторяемыйТест(3)
//  Процедура Проверка(&ИнформацияОПовторении Повторение) Экспорт
//      Сообщить(Повторение.ТекущееПовторение());
//      Сообщить(Повторение.ВсегоПовторений());
//  КонецПроцедуры
//
Процедура ПриСозданииОбъекта()
```

Возвращаемое поставщиком значение имеет тип [ИнформацияОПовторении](../Классы/ИнформацияОПовторении.md).
Номер начинается с единицы и не зависит от отображаемого имени вызова.

Поля получают значение после проверки условий и перед методами текущего повторения.
У одиночки поле обновляется перед очередным повторением; ранее полученные объекты сохраняют свои сведения.
Аннотация поля подходит для наборов, в которых все тесты повторяемые и нет методов уровня набора.
