# АннотацияИнформацияОПараметризованномВызове

## ПриСозданииОбъекта

```bsl
// Передает сведения о текущем вызове в параметр параметризованного теста,
// ПередКаждым, ПослеКаждого или в поле набора перед выполнением вызова.
// В обычном и повторяемом тесте, конструкторе, ПередВсеми и ПослеВсех
// значение недоступно: запрос вызывает ошибку разрешения значения.
// Умолчание параметра не используется при ошибке поставщика.
//
// Пример:
//  &ПараметризованныйТест
//  &ИсточникЗначение(11)
//  &ИсточникЗначение(22)
//  Процедура Проверка(Значение, &ИнформацияОПараметризованномВызове Вызов) Экспорт
//      Сообщить(Вызов.НомерВызова());
//      Сообщить(Вызов.Аргументы().Получить(0));
//  КонецПроцедуры
//
Процедура ПриСозданииОбъекта()
```

Возвращаемое значение имеет тип
[ИнформацияОПараметризованномВызове](../Классы/ИнформацияОПараметризованномВызове.md).
Объект содержит номер вызова с единицы и фиксированный список аргументов источника с индексами с нуля.
В примере вызовы получают списки `[11]` и `[22]`. Параметр `Вызов` OneUnit заполняет по его аннотации.
Другие параметры, заполняемые по своим аннотациям, например [`&ИнформацияОТесте`](ИнформацияОТесте.md),
в список не входят. Значения по умолчанию автоматически не подставляются.

Поля заполняются после проверки условий и перед методами текущего вызова.
Перед каждым вызовом теста OneUnit записывает в поле одиночки новый объект с информацией об этом вызове.
Аннотация поля подходит для наборов, в которых все тесты
параметризованные и нет методов уровня набора.
